# 先读我（5 分钟）

## 我们在干什么

做一个「实训室选拔录取」的**演示系统**，答辩用。业务上就是一个"招聘会后台"：

- 学生一次投 3 个导师意向（**不分先后**）
- 导师面试后发 offer，一个学生可能同时收到 3 个，但**只能签一家**
- 他不要的那一个名额，要自动给候补名单上的下一位
- 三轮补录之后，剩下的名额统筹调剂

**5 个页面**：`/apply` 填报、`/mentor` 导师、`/my-offers` 我的 offer、`/admin` 管理、`/public` 公示
**6 个功能**：填意向 → 打分 → 发 offer → 确认 → 递补 → 切换轮次

三个人都**不写代码**，做同一件事：

> 把需求说给 AI → AI 写 → **你亲手点一遍，看对不对**。

---

## 你只需要读两份

1. **本文件**（5 分钟）
2. **`docs/roles/` 里你那张角色卡**（5 分钟）

其他的都是**速查**，不用通读：

| 文件 | 什么时候看 |
|---|---|
| `docs/开工确认单.md` | 开工前看一遍，回"确认" |
| `docs/prompts/N号-口令.md` | **每天开工复制一个 T** |
| `docs/新手包/01-必懂的5件事.md` | 开工前扫一眼，10 分钟 |
| `docs/新手包/02-每天照做.md` | 第一次开工时对着做 |
| `docs/新手包/03-Git七条命令.md` | 装环境时看 |
| `docs/新手包/04-卡住了查这里.md` | **卡住了才看** |
| `docs/答辩.md` | 最后一周才看 |

**给 AI 看的只有 4 个**：`CLAUDE.md`、`docs/contracts.md`、`docs/rules.md`、`docs/roles/N.md`。
**`docs/新手包/` 永远不要给 AI 读**（里面有 git 命令，它可能真去执行）。

## 唯一一条不能破的规矩

> **只改自己名下的文件。**

需要别人的功能时，**假设它已经有了**，直接调用。不要替别人实现，也不要"顺手帮他改一下"。

## 时间线

```
D1      三人一起跑通空项目
D2      1 号交数据（字段 + 假数据 + db.py）← 全组等这一个
D3–D4   各自做页面
D5      合并验收（第一次拼起来）
D6–D9   各自往下做（2 号做 offer/递补，3 号做样式/公示）
D10     合并验收（主流程走通）
D11–D14 彩排、修 bug、PPT
D15     终演
```

**只有 4 个必须碰面的时刻**：D1 上午、D2 下午、D5 收工前、D10 收工前。
