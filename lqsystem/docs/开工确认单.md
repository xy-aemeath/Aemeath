## 一、技术栈（已定）

```
Python 3.11 + FastAPI + SQLite（Python 自带）+ 原生 HTML/JS
```

**为什么是它**（不用记，知道结论就行）：

- 三个人都小白，Python 代码最短最好读
- 一个 `app.py` 装下全部后端，不用学框架分层
- 数据库就是一个文件 `data.db`，不用装数据库软件
- 不用 React/Vue，不用 npm，不用打包工具
- 断网也能跑（答辩现场救命）

**不许引入**：React、Vue、TypeScript、SQLAlchemy 等 ORM、Bootstrap/Tailwind、任何"脚手架"。

**你要做的一件事**：确认自己电脑上装了 Python。

```
python --version
```

看到 `Python 3.12.x` 这类版本号就过。没有的话，在项目文件夹里开 `claude` 说：

```
帮我用 winget 装 Python 3.11，装完告诉我怎么验证。
```

## 四、状态词（已定，就这 6 个）

| 词 | 含义 | 用在哪 |
|---|---|---|
| `pending` | 待确认 | offer |
| `confirmed` | 已确认 | offer |
| `declined` | 已放弃 | offer |
| `expired` | 已失效 | offer |
| `open` | 可填报 | 轮次 |
| `closed` | 已关闭 | 轮次 |

**不许**：中文状态、`waiting`、`success`、`fail`、`done`、`1/2/3`。

调剂开关用 `1`（愿意）/ `0`（不愿意）。

## 五、接口返回格式（已定，就这一种）

```json
成功：{"ok": true,  "data": ...}
失败：{"ok": false, "msg": "名额已满"}
```

- `data` 可以是数组、对象、数字
- 失败时 `msg` 用中文，写给人看的话（"名额已满"而不是 "QUOTA_FULL"）
- **不许返回裸数组**（`[...]` 直接返回），否则前端一处写错就白屏
