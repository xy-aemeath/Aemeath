## 装环境

**`python` 没反应 / 弹出应用商店**
装了商店版或没勾 PATH。去 python.org 装 3.11，**第一步就勾 `Add Python to PATH`**，装完关掉所有命令行重开，`python --version` 验证。

**`pip install` 卡住**
加镜像：`pip install fastapi uvicorn -i https://pypi.tuna.tsinghua.edu.cn/simple`

**`address already in use`**
8000 被占。关掉所有黑窗口重试；不行就改 8001。

**双击 `start.bat` 黑窗一闪就没**
报错了但没看见。在 bat 最后加 `pause`，或从命令行跑 `python app.py`。

**改了代码页面没变**
改了 `.py` 要重启服务；改了 `.html` 用 **Ctrl+F5** 强刷。

## Git

**`git push` 被拒绝**
先 `git pull` 再 `git push`。

**手滑 `git add .`**
还没 commit 就 `git reset`，然后一个个 `git add 文件名`。

**误提交了 data.db**
`git rm --cached data.db` → commit → push。`--cached` 不能漏。

**冲突**
`git checkout -- 冲突文件` 然后 `git pull`，认了重做。

## 跟 AI 打交道

**它改了不属于我的文件**
`git checkout -- 那个文件`，然后告诉它"只改我指定的文件"。

**它一口气写了一堆功能**
喊停：`我只做 T3，只要 offer 列表和单个自动确认，其他删掉。`

**它说"已完成"但页面没变**
`git status` 看它到底改了啥。多半是改错文件、或没重启服务。

**它自己发明字段名（`state` 而不是 `status`）**
`字段名以 docs/contracts.md 为准：offers 是 status，把 state 全改回来，只改这一个文件。`

**越改越乱**
先 `git checkout -- 文件` 退回能跑的版本，再让它**重写这一个函数**，别继续修。

**代码我看不懂能直接跑吗**
能跑，但你必须点。看不懂代码，不影响你判断"点了确认该不该变成已确认"。底线是跑完 `git status` 确认没碰别人的文件。
