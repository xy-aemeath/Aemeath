## 任务顺序（做完一个停，等我确认）

### T1 管理员页第一版（D2）
`/admin`：表格显示每个导师一行 —— 实训室、导师、名额、已发 offer 数、已确认数、剩余；剩余为负标红。
**验收**：6 个导师 6 行；数字和 `/debug` 对得上。

### T2 三个按钮（D3）
每个都二次确认：
- 结算本轮并进入下一轮（pending → expired；本轮 closed；下一轮 open；没有下一轮就提示）
- 重置演示数据（清空 intentions/interviews/offers/waitlist，重新 seed，第 1 轮 open）
- 回首页
**验收**：点结算，当前轮次从 1 变 2。

### T3 公示页（D4）
`/public` 不需要登录：按实训室分组列出 `confirmed` 学生；顶部大字"名额总计 18 ｜ 已录取 X ｜ 空缺 Y"，三个数不相等就标红。
**验收**：手机浏览器能打开；数字自洽。

### T4 样式统一（D6–D7）
给 `contracts.md` 里那 7 个 class 写样式：白底、卡片、圆角、正文 ≥16px、主按钮深色填充、危险按钮红色。
每个页面顶部加导航条。
**验收**：5 个页面来回点，看起来是同一套；站远两米能看清。

### T5 启动脚本（D8）
`start.bat`：检查 python → 自动 `pip install` → 启动 → 等 2 秒开浏览器 → 末尾 `pause`。
`README.md`：三步跑起来。
**验收**：关掉所有窗口，双击一次能起来；报错时窗口不会一闪就没。
