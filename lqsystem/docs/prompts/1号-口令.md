```
2. curl -X POST /api/intentions 传上面 body → {"ok":true}
3. curl "http://127.0.0.1:8000/debug" 里 intentions = 3
4. 打开 /apply?student_id=1 能看到 6 个导师分组显示

【自检，做完再回我】
- 跑上面 3 条 curl，贴真实输出
- /debug 里 intentions 的行数贴出来
- 列出你改了哪些文件
```
