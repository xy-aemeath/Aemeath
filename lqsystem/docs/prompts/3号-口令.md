## T2 三个按钮（D3，演示控制台）

```
先读 CLAUDE.md、docs/contracts.md、docs/rules.md、docs/roles/3.md。

我是 3 号。做 T2：管理员页的三个按钮。这是答辩演示的控制台，最重要的一页。
只改 routes_admin.py 和 static/admin.html。

【做什么】三个按钮，每个都要二次确认弹窗

按钮 1「结算本轮并进入下一轮」→ POST /api/admin/settle-round
  - 本轮所有 pending offer → expired
  - 当前轮 status → closed
  - 下一轮 status → open
  - 如果没有下一轮，返回 {"ok":false,"msg":"已是最后一轮"}，不许崩

按钮 2「重置演示数据」→ POST /api/admin/reset-demo
  - 删除所有 intentions / interviews / offers / waitlist 记录
  - 所有轮次恢复：第 1 轮 open，其余 closed
  - **不要删 mentors / students / rounds**（那是基础数据）
  - 返回重置了多少条

按钮 3「回首页」→ 只是跳转

【完成定义】
1. 先发 2 个 offer，curl -X POST /api/admin/settle-round
   → {"ok":true}，且那 2 个 offer 的 status 都变成 expired
2. curl /api/admin/current-round → no=2, status="open"
3. 再连点 2 次 settle → 走到第 3 轮；第 4 次 → {"ok":false,"msg":"已是最后一轮"}
4. curl -X POST /api/admin/reset-demo → 返回删除条数；
   再查：intentions=0, offers=0, interviews=0, waitlist=0，但 mentors 还是 6、students 还是 24
5. 重置后 /api/admin/current-round 回到 no=1, status="open"

【自检，做完再回我】
- 按上面 5 条一条条跑，贴真实输出（尤其第 4 条的各表行数）
- 列出你改了哪些文件

不要问"这样可以吗"，跑通再来。
```

**你回来只检查：** 第 4 条——重置后基础数据还在（6 个导师 24 个学生），业务数据清零。**重置把导师删了就完了。**

## T5 启动脚本 + README（D8）

```
先读 CLAUDE.md、docs/contracts.md、docs/roles/3.md。

只改 start.bat 和 README.md。

【start.bat 要做】
1. chcp 65001（防中文乱码）
2. 检查 python 是否存在，没有就提示"请先安装 Python 并勾选 Add to PATH"然后 pause 退出

【README.md 要有】
1. 三步跑起来：装 Python → 双击 start.bat → 打开 127.0.0.1:8000

【完成定义】
1. 关掉所有窗口，双击 start.bat，浏览器自动打开并且页面正常
2. 故意改坏 requirements.txt 里的一个包名，双击 → 报错但不闪退（能看见错误）
3. 拔掉网线，双击 → 仍然能启动（不依赖外网）
```
