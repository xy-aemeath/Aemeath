# 口令 0：生成项目骨架

> **谁用**：1 号，第 1 天。
> **怎么用**：在项目文件夹里打开命令行，输入 `claude` 回车，把下面横线里的内容整段复制进去。

---

先读 `CLAUDE.md` 和 `docs/contracts.md`，然后按下面要求生成项目骨架。

## 技术栈

Python 3.11 + FastAPI + SQLite（用 Python 自带的 `sqlite3` 模块）+ 原生 HTML/JS。

- 不要 React / Vue / TypeScript
- 不要 ORM（SQLAlchemy 等）
- 不要任何 UI 框架（Bootstrap / Tailwind）

## 目录结构

```
app.py
db.py
routes_apply.py
routes_mentor.py
routes_admin.py
static/index.html
static/style.css
requirements.txt
start.bat
```

## app.py 要做的事

1. `GET /` 返回 `static/index.html`
2. `GET /health` 返回 `{"ok": true}`
3. 用 `StaticFiles` 托管 `static/` 目录
4. 挂上三个路由模块（`routes_apply`、`routes_mentor`、`routes_admin`），
   三个空模块里各写一个示例接口，返回 `{"ok": true, "data": []}`
5. 只监听 `127.0.0.1:8000`，不需要外网访问

## index.html 要写什么

一行大字"系统已启动"，下面列出 5 个页面的链接：
`/apply`、`/mentor`、`/my-offers`、`/admin`、`/public`。
现在点进去 404 没关系，只是先有个入口。

## requirements.txt

```
fastapi
uvicorn
```

## start.bat

1. 检查有没有 python，没有就提示"请先安装 Python"
2. `pip install -r requirements.txt`
3. 启动 uvicorn
4. 等 2 秒，用默认浏览器打开 `http://127.0.0.1:8000`
5. **末尾一定要有 `pause`**，这样报错时窗口不会一闪就没

## 不要做的事

- 不要建任何数据库表（下一步才做）
- 不要做任何业务功能
- 不要写测试
- 不要改 `CLAUDE.md`、`.gitignore`、`docs/` 下的任何文件

## 做完告诉我三件事

1. 需要执行哪几条命令、装哪些包
2. 怎么确认成功（具体到点哪里、看到什么）
3. **列出你改了哪些文件**
